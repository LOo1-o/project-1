# Как формируются Ключевые слова (Keywords) — Диаграмма потока

## Краткое резюме

Ключевые слова для поиска колонок в Excel НЕ просто берутся из Excel. Они конструируются на основе **реальных годов из Word документа** и текста подзаголовков Excel таблиц.

---

## 1. Откуда берутся годы (202X)?

### Источник 1: Word документ (приоритетный)
Когда генерируем теги в Word таблице, год **извлекается напрямую из заголовков колонок Word**:

```
Таблица 3. ВНЕОБОРОТНЫЕ АКТИВЫ ОРГАНИЗАЦИЙ ПО ВИДАМ ЭКОНОМИЧЕСКОЙ ДЕЯТЕЛЬНОСТИ

Внеоборотные активы  |  Внеоборотные активы
    2023            |        2024
```

Функция `_find_year_header_row()` в `logic.py` находит эти строки с годами и использует их для создания тегов.

### Источник 2: Excel (при динамической генерации column_mapping_v2)
Если теги еще не сгенерированы, годы определяются из подзаголовков Excel:

```excel
Валюта баланса               |  Внеоборотные активы
на конец предыдущего года    |  на конец отчетного года
```

Функция `_detect_year_by_text()` определяет год:
- `"предыдущий"` / `"2022"` → условный код `22` (первый год)
- `"отчетный"` / `"текущий"` / `"2023"` → условный код `23` (отчетный год)

## 2. Как формируются ключевые слова?

### Функция: `_extract_keywords_for_year(base_name, suffix, year)`

Для каждой колонки создается набор ключевых слов:

#### Пример 1: Столбец "Валюта баланса" на конец 2023

```
base_name = "Валюта баланса"
suffix = "на конец предыдущего года"
year = "22"  (из условного определения)
```

**Результат:**
```
keywords_2022 = [
    "2022",              # Явный год (если найдено в суффиксе)
    "предыдущий",        # Маркер периода для года 22
    "Валюта баланса"     # Базовое название
]

keywords_2023 = [
    "2023",              # Явный год
    "конец",             # Маркер периода для года 23
    "Валюта баланса"     # Базовое название
]
```

Это записывается в `column_mapping_v2.csv` как:
```csv
T24_000000_t01Ved14.xlsx;Валюта баланса;ValBal;3;4;"2022","предыдущий","Валюта баланса";"2023","конец","Валюта баланса"
```

## 3. Как используются ключевые слова при заполнении?

### Процесс в `data_filler_v2.py`:

**Шаг 1:** Загружаем ключевые слова из `column_mapping_v2.csv`
```python
keywords_2022 = ["2022", "предыдущий", "Валюта баланса"]
keywords_2023 = ["2023", "конец", "Валюта баланса"]
```

**Шаг 2:** Используем `_find_column_smart()` для поиска колонки в Excel
```python
col_idx_2022 = _find_column_smart(df, col_22_hardcode, "2022", keywords_2022)
col_idx_2023 = _find_column_smart(df, col_23_hardcode, "2023", keywords_2023)
```

**Шаг 3:** Функция `_find_column_smart()` применяет 3-ступенчатую стратегию:
1. **Жесткий индекс** — если указан конкретный номер колонки (самый быстрый)
2. **Поиск по ключевым словам** — если жесткий индекс не подходит
3. **Поиск по году** — финальный fallback

## 5. Где ошибка, если данные не найдены?

| Проблема | Диагностика | Решение |
|----------|------------|---------|
| Неправильный Excel источник | `table_source_data_mapping.csv` не совпадает с заголовком Word | Проверить имя таблицы в Word против маппинга |
| Keywords не совпадают | Подзаголовок в Excel не содержит ключевых слов | Обновить `column_mapping_v2.csv` вручную или регенерировать |
| Колонка не найдена | Жесткий индекс устарел после добавления новых столбцов в Excel | Пересчитать индексы или использовать keywords |
| Условный код не переводится в реальный год | `_map_year_to_suffix()` дает неправильный результат | Проверить логику определения года |

## 6. Откуда берется "2022" и "2023" в Keywords?

### Вариант А: Явное присутствие в Excel
Если в подзаголовке Excel есть `"2022"` или `"2023"`, они извлекаются regex:
```python
year_match = re.search(r'(202\d)', suffix)
if year_match:
    keywords.append(year_match.group(1))
```

### Вариант Б: Определение по тексту
Если года нет, используются маркеры:
```python
if year == '22':
    keywords.append('2022')  # Условное преобразование
elif year == '23':
    keywords.append('2023')  # Условное преобразование
```

### Вариант В: Из Word таблицы (приоритетный)
Реальные годы из Word напрямую передаются в теги и затем при заполнении переводятся в условные коды для поиска.

## 7. Резюме для разработчиков

**Key Points:**

1. **Keywords в `column_mapping_v2.csv`** — это не просто копия Excel. Это **специально сконструированные ключевые слова** на основе анализа структуры Excel.

2. **Годы (2022/2023/2024)** в keywords:
   - Либо **явные из Excel** (если есть в подзаголовке)
   - Либо **условные** ("2022" для `year='22'`, "2023" для `year='23'`)
   - Либо **реальные из Word** при генерации тегов

3. **При заполнении**, реальные годы из Word (202X) преобразуются в условные коды (22/23) для совместимости с master_data.

4. **Fallback механизм** обеспечивает то, что если первый год не найден, пробуется альтернативный.
